# Personal Oura Notion Helper

This is a private, single-user tool for comparing the owner's Oura daily readiness and sleep summaries with the owner's Notion recovery ledger. It runs on the owner's computer. The current setup stage permits a manually started, bounded, read-only comparison. Copying summaries into Notion requires separate owner approval.

This repository contains public information about the tool. It does not host the tool, accept sign-ups, or contain health records or credentials.
